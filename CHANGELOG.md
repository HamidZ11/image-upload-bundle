# Changelog

## 1.0.0 — prepared, not yet released

- MIT licence for the reusable bundle.
- Configurable image upload directory, file-size limit and pixel limit.
- JPEG, PNG and WebP validation, including content and corruption checks.
- Random filenames, safe file removal and optional PSR logger integration.
- Reusable Symfony form type and uploader service with shared validation policy.
- Independent tests using a minimal Symfony host without Doctrine or application entities.

Create the `v1.0.0` Git tag only after reviewing and testing the public repository.
Composer derives the package version from that tag; no hard-coded version field is needed.
